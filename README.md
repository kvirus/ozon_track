# Ozon Track Bot

Телеграм-бот, который следит за посылкой на [tracking.ozon.ru](https://tracking.ozon.ru) и присылает в группу сообщение, когда у заказа появляется новый статус или место (перемещение).

Проверка выполняется раз в час (`POLL_INTERVAL_SECONDS`, по умолчанию `3600`). Состояние сохраняется на диск, поэтому бот не теряет историю между перезапусками и не присылает старые события повторно.

## Как это работает

Страница `tracking.ozon.ru` — Nuxt SPA. Номер заказа берётся из query-параметра:

```
https://tracking.ozon.ru/?track=<номер>
```

Фронтенд запрашивает данные у BFF:

```
GET https://tracking.ozon.ru/p-api/ozon-track-bff/tracking/<номер>
```

Ответ содержит:

- `deliveryType` — тип доставки (`PVZ`, `Post`, курьер и т.д.);
- `deliveryDateBegin` / `deliveryDateEnd` — период доставки;
- `items[]` — список событий `{ "event": "...", "moment": "..." }`.

Пока событие не наступило, `moment` у него пустой. Именно поэтому на странице напротив будущего пункта нет даты. Когда дата появляется — событие состоялось.

Бот не парсит вёрстку, а перехватывает JSON-ответ этого API внутри Playwright. Это устойчивее к изменениям DOM.

### Antibot

И страница, и API закрыты Antibot Challenge Ozon: обычный `curl`/`requests` получает `403` с JS-челленджем. Поэтому используется headless Chromium через Playwright, который выполняет челлендж и получает cookie. Профиль браузера сохраняется в `BROWSER_DIR` (по умолчанию `/data/browser`), чтобы cookie переиспользовались между проверками.

## Логика уведомлений

Каждое событие идентифицируется ключом:

```
event | moment | location
```

- `event` — код статуса, например `InTransitRecipientCity`;
- `moment` — время события;
- `location` — место, если API его возвращает (поля `location`, `city`, `warehouse`, `place`, `address`, `facility`, `point`).

При каждом запуске контейнера бот сразу отправляет в чат сообщение «Бот запущен и следит за заказом» вместе с текущим статусом из сохранённого состояния. Это подтверждает, что контейнер поднялся, Telegram доступен и отправка работает. Если статуса ещё нет, бот пишет, что идёт первая проверка.

При первом запуске (когда истории ещё нет) бот запоминает всё, что есть в трекинге, и отправляет одну сводку «Беру заказ под наблюдение». Историю он не спамит.

Оба сообщения отключаются через `NOTIFY_ON_START=false`.

При следующих проверках любое новое событие с непустым `moment` (или изменившееся место) считается перемещением и отправляется в группу:

```
Перемещение по заказу 1234567890

Заказ везут
28.10.26, 09:30
Место: Сортировочный центр, Москва

Следующий этап: Заказ в пункте выдачи
Период доставки: 23.10.26 - 01.11.26
```

Если заказ перестал находиться (API вернул `404`), бот один раз сообщит об этом.

## Структура проекта

```
.
├── app/
│   ├── main.py       # точка входа, Telegram-бот, цикл проверок

├── requirements.txt
└── .env.example
```

## Быстрый старт (Docker)

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Добавьте бота в группу. Права администратора не обязательны.
3. Скопируйте конфиг и заполните значения:

```bash
cd /Users/bordacevkonstantin/git_my/ozon_track
cp .env.example .env
```

```dotenv
TELEGRAM_BOT_TOKEN=123456789:AA...
TELEGRAM_CHAT_ID=-1001234567890
OZON_TRACK_URL=https://tracking.ozon.ru/?track=0000000000
```

4. Узнать `TELEGRAM_CHAT_ID` группы: запустите бота и отправьте в группе команду `/id`.

5. Запуск:

```bash
docker compose up -d --build
docker compose logs -f
```

Остановка:

```bash
docker compose down
```

## Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | Токен бота от BotFather (обязательно) |
| `TELEGRAM_CHAT_ID` | — | ID группы или чата, куда слать уведомления (обязательно) |
| `OZON_TRACK_URL` | — | Полная ссылка отслеживания, номер берётся из `?track=` |
| `OZON_TRACK_NUMBER` | — | Номер напрямую; имеет приоритет над ссылкой |
| `POLL_INTERVAL_SECONDS` | `3600` | Интервал проверки в секундах (минимум 60) |
| `NAV_TIMEOUT_SECONDS` | `90` | Таймаут открытия страницы и ожидания API (минимум 30) |
| `HEADLESS` | `true` | Запускать браузер без окна |
| `NOTIFY_ON_START` | `true` | Отправлять сообщение о запуске и сводку при первом запуске |
| `STATE_FILE` | `/data/state.json` | Файл состояния |
| `BROWSER_DIR` | `/data/browser` | Профиль Chromium (cookie antibot) |
| `TZ` | `Europe/Moscow` | Часовой пояс для дат и времени |
| `LOG_LEVEL` | `INFO` | `DEBUG`, `INFO`, `WARNING`, `ERROR` |

Достаточно задать либо `OZON_TRACK_URL`, либо `OZON_TRACK_NUMBER`.

## Команды бота

| Команда | Действие |
|---|---|
| `/start`, `/help` | Краткая справка |
| `/status` | Текущий статус из сохранённого кеша, без запроса к Ozon |
| `/check` | Принудительно проверить заказ прямо сейчас |
| `/id` | Показать `chat_id` текущей группы |

Команды работают в группе и в личке с ботом.

```bash

export TELEGRAM_CHAT_ID=...
python -m app.main
```

## Состояние

Файл `STATE_FILE` имеет вид:

```json
{
  "tracks": {
    "0000000000": {
      "seen": [
        "Created|2026-10-23T07:00:00Z|",
        "InTransitRecipientCity|2026-10-27T08:52:00Z|"
      ],
      "not_found": false,
      "updated": "2026-10-28T06:45:00+00:00",
      "data": { "items": [] }
    }
  }
}
```

`seen` — уже отправленные события. `data` — последний ответ API для `/status`.

Сбросить историю и получить сводку заново:

```bash
rm -f data/state.json
```

## Отладка

- **`Не получили ответ API tracking.ozon.ru`** — скорее всего не пройден Antibot. Бот сохраняет скриншот и HTML страницы в `/data/debug`. Увеличьте `NAV_TIMEOUT_SECONDS`, проверьте доступ к `tracking.ozon.ru`, при необходимости удалите `data/browser` и дайте боту получить свежие cookie.
- **`Заказ ... не найден`** — неверный номер или заказ ещё не зарегистрирован в трекинге. Проверьте ссылку через `--once --dump`.
- **Долго собирается образ** — Chromium и системные зависимости Playwright скачиваются на этапе `docker compose build`. Это нормально.
- **Apple Silicon / ARM** — в `docker-compose.yml` стоит `platform: linux/amd64`, потому что Chromium для Playwright под Linux ARM нестабилен. На x86-сервере эту строку можно удалить. Эмуляция amd64 на Mac работает, но медленнее.
- **Пустой `moment` у события** — это нормально: этап ещё не наступил. Бот отправит уведомление, когда время появится.

## Безопасность

- `.env` и `data/` исключены из git. Не коммитьте токен бота.
- Токен даёт полный контроль над ботом: при утечке перевыпустите его в BotFather.
- Бот только читает публичную страницу трекинга; авторизация Ozon не используется.
